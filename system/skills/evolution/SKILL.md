# Evolution

Promote a lesson when it changes a future decision. Identify the observation,
its source, the proposed explanation and the conditions under which it should
transfer. Repeating one workflow is not independent validation; consider
alternative explanations and counterexamples. State whether a lesson is
tested, tentative or limited to the case instead of assigning confidence from
a session count.

Prefer correcting the existing decision point to adding another rule.
Generalize the reason, not the case's protein, mass, scan or successful action
sequence. Interface constraints belong with their owning interface. One-off
parameters and findings stay with the analysis; a session need not add guidance.

Removing names and numbers does not make a case's preferred route general.
Check that the proposed method still makes sense when evidence supports a
different outcome. Specialized knowledge needs source support and explicit
applicability limits; a precedent does not prescribe the next case's answer.

Evaluate method changes on untouched problems with different valid routes and
on problems that remain unresolved. Expected answers belong to evaluation,
outside app-facing assets. Assess the supported claim and investigative scope,
not conformity to one tool-call sequence. Re-running the development case
checks that case; it is not independent evidence of generalization.

## Destination

- Method or procedure: the relevant Workspace Skill.
- Transferable knowledge: an existing shared wiki page, or one concept per
  new page with title, kind, updated and optional tags; use [[Page]] links.
- Case finding: Workspace wiki/, with its sources and limits.

Search the relevant location before adding content. Resolve contradictions
with existing guidance and preserve the origin of corrected claims.
system-wiki/ is the shared virtual file prefix, not a shell path. Installed
System Skills are maintained through explicit product maintenance; routine
analysis improvements use Workspace Skills or proposals for that maintenance.
