# Reporting a hypothesis comparison

Lead with the answer, the observations that decide it and the remaining
uncertainty. Adapt the amount of detail to the user's question. A short
comparison may need only a figure and a paragraph.

For a substantial investigation, this structure can help:

- Object: accession, feature/scan IDs, mass basis and observed shift.
- Working models: composition/ProForma, site state, origin and why retained.
- Deciding measurements: observations, common settings, interpretation and
  artifact/figure links.
- Reference knowledge: annotations, literature, user hypotheses or AI judgment,
  distinguished from measurements in this sample.
- Remaining alternatives: residuals, grouped or untested candidates, limitations
  and the next observation that could change the explanation.

Use a table when models or measurements are easier to compare side by side.
Optional columns are model, prediction, observation, interpretation and source.
Include reported Smith levels or E-value information only when useful and
supported by the source/tool. Subjective review weights are optional; explain
their basis and do not present them as formal confidence.

Embed the deciding figures beside the interpretation. Link full search outputs
and match tables rather than reproducing them. Progress updates report what
changed; final delivery should answer the question without requiring the user
to reconstruct the conversation. No fixed table cadence or duplicate report
file is required. Explicit human decisions use human-decision.md.
