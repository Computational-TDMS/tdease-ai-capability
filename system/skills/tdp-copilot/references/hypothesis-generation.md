# Hypothesis-generation methods

Use these domain methods under the shared scientific investigation principles
when they address the open question. This file adds no required sequence.

## Construct explanations

Start with the observed signed shift, its uncertainty and mass basis, backbone,
terminal processing and assigned components. Candidate ideas may come from
database records, family patterns, literature, the user or domain memory.
Keep their origins visible; use AI judgment for an uncited recollection.

Connect a useful prior to the observed quantity: what explanation does it
suggest, what remains unaccounted for, and what observation could support or
contradict the whole model? Evaluate partial agreements and disagreements in
that model's context. Reference knowledge proposes explanations; it does not
assign them to the sample.

A promising component need not explain the whole observation by itself.
To explore it, state a conditional model: its reference backbone, the
component's origin and status, the remaining signed residual, and what could
distinguish it from a model without that component. A source-supported change
of reference creates another accounting basis, not another observed molecule
by itself. Recalculate from the same observation in that basis before querying
or reusing a mass-search result. These are ways to develop an explanation,
not a requirement to pin every motif hit or enumerate all processing states.

For mass calculations and spectral testing, use the kernel's exact composition
and ProForma representation. An open numeric residual is a legitimate
hypothesis, but is not a complete chemical model for confirmatory comparison.

Possible explanations include combinations of PTMs, terminal processing,
truncation, sequence variants/paralogs, disulfides, preparation chemistry,
adducts and isotope-registration errors. Choose those relevant to the source;
a PTM-library no-hit does not exhaust these possibilities.

When a search stalls, identify what it held fixed: backbone, terminal state,
library, sites, event count and uncertainty. Revisit a source-supported
assumption or obtain a different kind of evidence when that could change the
candidate set. Widening the same lens without a scientific reason adds little;
an available informative lookup or measurement belongs to the current
investigation rather than being deferred automatically to another user turn.

## Decompose when useful

resolve-shift proposes component intervals and residuals from MS2. Inspect the
supporting fragments and reconcile useful independent scans. Localized
components can guide the next residual search; preserve their uncertainty and
keep source assignments distinct from proposals.

A component placed in an uncovered interval may improve an aggregate score
without being observed. Test alternatives against the local fragments that
would differ, rather than letting a decomposition score fix the background.

## Keep complete alternatives comparable

A model states the backbone/processing, components, placement or interval, mass
accounting, origin and a prediction that differs from another explanation.
Keep each decomposition path whole. Recombining convenient components from
different paths creates a new hypothesis, whose origin should be explicit.

Mass closure can hold for several models. Rank them using source constraints
and biological context, group those that predict the same available signals,
and test the strongest distinguishable alternatives. Preserve the complete
solver output and identify any untested remainder.

When no named model closes, retain the signed residual with its frame,
uncertainty, source and accounted components. Do not erase it from a model
merely because the generated ProForma contains only named tags.

## Family and reference context

Source-compatible features can suggest a shared increment or alternative
terminal representation. Check isotope-registration chains before treating
each rung as distinct chemistry. Keep member IDs, mass/RT context and spread;
recurrence does not transfer a modification or site between features.

Annotations, homolog alignments and conserved motifs can prioritize models.
Record taxonomy and coordinate mapping when transferring a site prior.
Absence of an annotation limits that query, not the sample's chemistry.
