# Site and sequence maps

Template-maintenance ideas, not additional shipped routes. Consult INDEX.md
before choosing a runtime figure.

Use sequence position as a shared axis when comparing sites, domains and
coverage. Declare reference sequence, numbering, processed-chain offsets and
alignment gaps. Plot only tracks whose observations or annotations are supplied.

Choose a view for the question: a lollipop shows site values, a matrix shows
sample-by-event patterns, and linked tracks show coordinate relationships.
Marginal summaries and extra domain tracks are useful only when they clarify
those relationships.

Keep event identity, value and uncertainty distinct. State sorting, denominators
and missingness. Overlapping annotations may need lanes or explicit grouping;
they should not imply measured co-occurrence on one molecule.

Labels, legends and the static view carry the result. Linked hover/zoom can
reveal details while preserving the shared coordinate system. Structural
context needs its own sequence-to-structure mapping.
