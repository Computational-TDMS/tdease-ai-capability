# Spectrum and isotope mirror views

Template-maintenance reference. Match the actual source domain:
fragment-annotation displays assigned spectral peaks; envelope-mirror displays
raw isotope windows and theoretical sticks.

Align paired views on one stated mass/m/z axis. Normalize intensities separately
when comparing shape; preserve common scaling when comparing amount. State the
choice. A mirror layout does not make different acquisition conditions
directly comparable.

Use stable ion-series colors and legends from shipped tokens, distinguishing
unassigned observations from theoretical predictions. Captions retain source,
scan, activation, tolerance and normalization. Assignments come from the
scientific producer, not proximity judged in the browser.

Link peaks and residue coverage only where the adapter supplies verified
coordinates. Provide readable labels and useful zoom for dense regions.
Missing expected ions require sensitivity/context interpretation; a faint
theoretical stick is not an observed match.

Keep exact plotted peaks and assignments with the figure. Static export retains
the relevant comparison and settings; hover provides detail, not its sole basis.
