# Third-party asset provenance

Runtime assets are vendored so generated figures remain offline and archival.

| Asset | Version/source | Local notice |
|---|---|---|
| D3 | d3 v7.9.0 | `assets/d3/LICENSE`, `assets/d3/README.md` |
| 3Dmol.js | 3dmol v2.4.0; version and authors in the vendored file header | `assets/vendor/3Dmol.min.js` |
| Tol palettes | Paul Tol color schemes | `assets/tol-colors/README.md` |

The application-specific templates, adapters, and examples are maintained in
this package. Historical consolidation notes and superseded capability counts
belong to Git history, not the runtime Skill.
