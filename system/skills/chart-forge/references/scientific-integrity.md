# Scientific figure safeguards

Use these rules when the corresponding figure family is selected.

## Top-down MS and PTM

- Annotated spectra state fragment tolerance and activation. Competing models
  share axes and are compared symmetrically.
- Isotope-family evidence is carried by spacing and recurrence, not decorative
  color. Candidate overlays are not observations.
- OpenSearch census marks remain linked to their cluster and verdict source;
  attention bars are questions for review, not chemical identities.
- Coverage ribbons are emitted only from asserted fragment-to-residue rules.
- A shape correlation or envelope fit is not an identity score.

## Quantification and Differential Results

- State sample count, uncertainty definition, thresholds, and multiple-testing
  method in the contract or figure.
- Missing and failed replicates remain gaps; never coerce them to zero.
- A volcano plot should be paired with an MA view when the requested conclusion
  depends on abundance-dependent behavior.

## Embeddings and Dense Views

- UMAP/PCA position is an exploratory projection. Do not turn visual distance,
  cluster area, or apparent separation into an unsupported quantitative claim.
- A dot plot that encodes fraction by size and expression by color shows both
  legends and keeps mappings fixed across panels.
- Dense feature maps use canvas only for marks; labels, axes, provenance, and
  interaction state remain inspectable.

## General

- Static output must preserve the meaning; hover only reveals detail.
- Color is never the sole discriminator for a scientific category.
- The caption and manifest must agree with the actual plotted fields and scale.
