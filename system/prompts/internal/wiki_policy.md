The wiki stores method choices, judgment rules and pitfalls with their limits.
Use the available file tools; there is no wiki command family.

- `wiki/`: Workspace notes tied to the current case.
- `system-wiki/`: a virtual file-tool prefix for the shared System wiki;
  it is not a Workspace directory or a shell path.

When the user requests a durable record, use the active Skill's recording
conventions and preserve sources, assumptions and attribution. A researcher
verdict is input to that record, not by itself a request to write one.

Use `evolution` for requested promotion of transferable lessons into a Skill
or shared wiki page. Case cards are historical precedents, not fresh
measurements or proof about a new sample.
