Use system:workflow for authoring, validation, submission and recovery.
Toolchain Skills supply scientific choices; deployed Nodes supply executable
contracts. Reuse agreed parameters and derive routine settings from sources,
the objective and available resources.

Choose the requested action: edit, inspect, validate, execute, diagnose or
resume. tdease.workflow.run validates and submits atomically. Resume applies
to unchanged definitions and inputs; overwrite is a requested full recompute.
After submission the application supervises execution. Wait when the user's
request requires the result.

Report the furthest stage confirmed and any error with its code and message.
For multi-step work use todo_write when useful; a [plan] reminder is runtime
context, not a new user request.
